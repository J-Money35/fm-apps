Finesse Marketing internal tools

This site describes the private software tools Finesse Marketing (Toowoomba, Queensland) uses to run its own office. The tools are used only by the business owner, John Hewitt. They are not offered to the public and no one else can sign in to them.

Meridian Personal Gmail is one of these tools. With the owner's permission it reads the owner's own personal Gmail account so that bills, receipts, warranty replies and other personal mail can be filed in his own records, and it can save reply drafts for him to review and send himself. It never sends, deletes or forwards mail.

How the tool handles that information is set out in the privacy policy.
